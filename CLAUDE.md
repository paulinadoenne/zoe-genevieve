# Hinweise für Claude

- Das Projekt ist über Vercel deployed. Nach jeder Änderung automatisch committen und pushen (kein Nachfragen nötig).
- Immer direkt auf den Branch `main` pushen (nicht auf einen Feature-Branch).
- Alle Inhalte (Preise, Adresse, Öffnungszeiten, Kontakt, Texte) stehen zentral in `lib/content.ts`.
- In Website-Texten keine Gedankenstriche (—) verwenden. Stattdessen Komma, Klammern oder `·`. Code-Kommentare sind davon nicht betroffen.
